💾 Guardar y volver a abrir el programa

Tus registros se guardan automáticamente en este dispositivo. Descarga una copia del programa para conservarla en tu carpeta de Descargas y abrirla nuevamente cuando la necesites.

✅ Guardado automático activado.
Para compartir: presiona 📤 Compartir programa y elige WhatsApp, correo, Bluetooth, Drive u otra aplicación. Si tu navegador no permite compartir archivos directamente, el programa se descargará para que lo adjuntes manualmente.

Para volver a entrar: abre la carpeta Descargas de tu teléfono o computadora y selecciona el archivo Granja-Ponedora.html. En Android también puedes abrirlo con Chrome y usar el menú ⋮ → “Agregar a pantalla principal”.
Aviso: esta aplicación funciona como bitácora administrativa. No recomienda medicamentos, antibióticos, dosis o tratamientos. Las vacunas, protocolos y rangos deben configurarse con un veterinario o técnico de la región.
